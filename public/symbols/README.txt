Catatan:
- Format file: PNG transparan (disarankan resolusi 256x256 atau 512x512).
- Jika file belum ditaruh di folder ini, aplikasi secara otomatis menampilkan placeholder kotak taktis resmi bersandi sektor tanpa error.
- Cukup ganti file di folder ini dan refresh browser tanpa perlu mengubah baris kode apa pun.
